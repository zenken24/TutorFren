# TutorFren: non-negotiable rules

1. Voice audio is NEVER persisted server-side: no storage bucket, no DB column, no log line.
   Audio lives only in Edge Function memory and in the app cache until a finally{} deletes it.
2. Every table has RLS enabled, deny by default. Writes to attempts, explanations,
   concept_mastery happen only in Edge Functions using the service role.
3. Roles come from public.profiles (or app_metadata via the access-token hook), NEVER user_metadata.
4. Guardians have no direct SELECT on learning tables; they call guardian_summary(), which
   checks active link + active consent and returns aggregates only.
5. The service_role key never appears in apps/mobile or any client bundle.
6. Never log request bodies, transcripts, tokens, names, emails or phone numbers.
   Log request_id, hashed user ref, route, status, latency only.
7. The LLM never gets DB access or tools. Redact phone/email from student text before any LLM call.
8. Children have no password. They are paired by a guardian (one-time code, or shared-phone mode).
   Guardian mode is locked; risky guardian actions need a server-checked sign-in within 5 minutes.
9. Seed and demo data are synthetic and labelled as such.
10. SECURITY DEFINER functions: set search_path = '', check auth.uid(), revoke from public/anon.
11. LLM = Google Gemini via @google/genai, ONLY through supabase/functions/_shared/llm.ts.
    GEMINI_API_KEY_DEV is for synthetic data only; real children's data goes only to
    GEMINI_API_KEY_PROD. Never put a Gemini key in apps/mobile.

## Conventions
- Expo SDK 58: routes are in apps/mobile/src/app/. Check versioned Expo docs before using an Expo API.
- Textbook: content/textbook/index.json is generated by content/scripts/textbook/build_index.py. Do not hand-edit it.
- @google/genai 3.x: use ai.interactions.create (response_format, safety_settings, store:false); the old
  responseMimeType/responseSchema config is deprecated.
